# lx-01: `PROP_SEED` property-suite sweep

## Method

- Swept seeds **1–200**, running the complete `deno task test:prop` suite once for each seed.
- Command: `deno run -A work-scripts/deno/prop-seed-sweep.ts --start 1 --count 200 --jobs 3`.
- The eight-worker attempt on this 8 GB VM was killed by the kernel OOM killer before completing any seeds.
  The sweep was restarted from seed 1 with three workers; no OOM kill recurred.
- An earlier two-seed sanity check was clean: 63 property tests passed per seed, with three expected ignores.

## Results

The sweep completed all 200 seeds: **182 clean, 18 failed**. Failures grouped by test or process failure:

| Invariant / failure family                                                                                          | Failing seeds                              |
| ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| `rules_test.ts`: reachable-state generators cover playing, won, draw, and full boards                               | 21, 30, 39, 42, 51, 99, 143, 145, 152, 183 |
| `offsets_test.ts`: exactly-once ingestion across adversarial append/truncate/rewrite/remove/ingest interleavings    | 44, 126                                    |
| `rotation_test.ts`: generator covers today's directory, open file, stale directories, `.gz` files, and cap pressure | 24                                         |
| Process exit 139 (SIGSEGV; no failed test parsed; last reported file was `offsets_test.ts`)                         | 14, 96, 179, 187, 199                      |

All other seeds passed the full property suite.

## Verdict

The suite is seed-sensitive: the same rules coverage failure reproduced when seed 21 was rerun, and the sweep
found additional fixed seeds that miss the rules, offsets, and rotation properties. These are property or
generator coverage failures rather than random timing variation. Separately, five seeds terminated with exit
139 after no test failure was parsed; those process crashes need independent investigation. A clean run on an
arbitrary seed is not enough to establish that this property suite is reliable across seeds.
