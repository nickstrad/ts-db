## Result

**No drift in the README Configuration table:** all 26 options match `platform/config.ts`'s `OPTIONS` table
for option name, env var, type, default label, and description. Each README row and its corresponding
options-table row are cited below. `ConfigLive` snapshots `Deno.env.toObject()` once, iterates `OPTIONS`,
looks up each declared `envVar`, and applies that row's default when unset or empty
(`platform/config.ts:367-384`, `platform/config.ts:493-499`). The effective defaults and cross-option
validation are assembled at `platform/config.ts:400-485`.

The docs' broader statement that `platform/config.ts` is the “single env boundary” should be read as the
platform configuration boundary. Other executable demo and test code makes direct reads, including names not
declared in `OPTIONS`. Those reads are catalogued separately below; no evidence indicates they are stale/dead
configuration options.
